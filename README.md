# PLAKATWERK

Website für Druck, Plakatierung in Münster und Tickets.

## Gestaltung

Stadtzeichen-Design, Stand 29.10.2026: Waldschwarz, warmes Gelbgrün, eigenständige Typografie und Münster-Grafik. Einstieg: index.html. Gemeinsame Gestaltung: platform25.css und stadtzeichen.css.

## GitHub Pages

https://emmosk2607.github.io/plakatwerk/

GitHub Pages zeigt eine statische Gestaltungsvorschau. Kundenkonten, Aufträge, Datei-Uploads und Ticketbuchungen benötigen den separaten Node-Server aus dem lokalen Projekt Version 2.5. Sie sind auf GitHub Pages nicht verfügbar. Keine echten Zahlungen.

Private Serverdaten, Sitzungen, Kundendaten und Zugangsdaten gehören nicht in dieses Repository.

## Prüfung

12 automatisierte Funktionstests bestanden. Startseite, mobiles Menü, Ticketseite und Login im Browser geprüft.
